# Keyboard shortcuts

Spinus's keys, in one place. The ones in the first tables are commands: change them in **Options ›
Keyboard shortcuts...** (see [The main window](main-window.md#keyboard-shortcuts)). Keys inside a panel
are fixed.

The commands work in every Spinus window: the main window, a panel in its own window, a plugin's window
and Spinus Tune. In a text field (the Browser's search, a name), keys with **Ctrl** and a number or a sign
(**Ctrl+Alt+1**, **Ctrl+=**) are commands too; with a letter (**Ctrl+A**, **Ctrl+C**) they stay with the
text. A plugin's own window, drawn by the plugin, keeps the keys it is given.

## Panels

| Key | Opens or closes |
|---|---|
| **F5** | Playlist |
| **F6** | Channel Rack |
| **Shift+F6** | [Audio tracks](audio-tracks.md) |
| **F7** | Piano Roll |
| **F8** | Browser |
| **F9** | Mixer |
| **F10** | [Audio settings](audio-settings.md) |
| **F1** | The [manual](help.md), with its search |
| **Ctrl+H** | History |
| **Ctrl+Shift+A** | [Assistant](assistant.md) |
| **Ctrl+Alt+1**, **2**, **3** | The Compose, Arrange and Mix [layouts](main-window.md#layouts) |
| **Ctrl+Alt+4** to **9** | Your own saved layouts, in the order saved |

The Launcher, Routing, Automation editor, Analyzer and Automixer open from the **View** menu. The
Analyzer is experimental: it is in the menu (and in **Options › Keyboard shortcuts...**) only while
**Show experimental features** is ticked in **Options › AI...**.

## Playing and recording

| Key | Does |
|---|---|
| **Space** | Play or stop |
| **L** | Pattern or song mode |
| **R** | Arm recording |
| **Ctrl+M** | Metronome on or off |
| **Ctrl+T** | Typing keyboard to piano: the computer keyboard plays notes ([how](piano-roll.md#playing-with-the-computer-keyboard)) |

## Files and editing

| Key | Does |
|---|---|
| **Ctrl+N** | New project |
| **Ctrl+O** | Open a project |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save as |
| **Ctrl+R** | [Export audio](export.md) |
| **Ctrl+Q** | Quit |
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** | Redo |

## Tools (Piano Roll and Playlist)

They pick the tool in the Piano Roll when it is in front, otherwise in the Playlist.

| Key | Tool |
|---|---|
| **P** | Draw |
| **B** | Paint |
| **C** | Slice |
| **E** | Select |

## Inside the Piano Roll, Playlist and Automation editor

| Key | Does |
|---|---|
| **Ctrl+A** | Select all |
| **Escape** | Select none |
| **Delete** | Delete the selection |
| **Ctrl+C**, **Ctrl+X**, **Ctrl+V** | Copy, cut and paste notes (Piano Roll) |
| **Ctrl+B** | Duplicate the selection right after itself (Piano Roll) |
| **Alt** while dragging | Off the grid; in the Playlist, Alt+dragging an audio clip's end stretches it |
| **Ctrl**+wheel, **Ctrl+Shift**+wheel | Zoom time, zoom key height (Piano Roll) |

## Launcher

Click the Launcher first.

| Key | Does |
|---|---|
| Arrow keys | Choose a slot |
| **Enter** | Launch the chosen clip (or put the current pattern in an empty slot) |
| **Ctrl+Enter** | Launch the chosen slot's scene |
| **Shift+Enter** | Stop the chosen slot's column |
| **Delete** | Empty the chosen slot |
